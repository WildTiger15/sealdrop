## Benchmarks (criterion, native, release build; median)

### Key exchange and signatures

| Operation | Post quantum | Classic | PQ / classic |
|---|---|---|---|
| KEM keygen | 194.2 µs | 32.5 µs | 6.0× |
| KEM encapsulate | 174.0 µs | 124.8 µs | 1.4× |
| KEM decapsulate | 302.4 µs | 83.4 µs | 3.6× |
| Signature keygen | 653.0 µs | 22.7 µs | 28.8× |
| Sign | 1573.3 µs | 33.2 µs | 47.3× |
| Verify | 248.9 µs | 57.1 µs | 4.4× |

Post quantum = X-Wing (X25519 + ML-KEM-768) and ML-DSA-65; classic = X25519 alone and Ed25519.

### File encryption throughput

| File size | SealDrop seal | SealDrop open | Classic seal (X25519 + Ed25519, same format) | Classic, no signature | SealDrop / classic seal |
|---|---|---|---|---|---|
| 64 KiB | 1.700 ms (36.8 MiB/s) | 0.669 ms (93.5 MiB/s) | 0.313 ms (199.4 MiB/s) | 0.116 ms (537.1 MiB/s) | 5.43× |
| 1024 KiB | 7.946 ms (125.8 MiB/s) | 5.428 ms (184.2 MiB/s) | 5.139 ms (194.6 MiB/s) | 1.355 ms (738.3 MiB/s) | 1.55× |
| 16384 KiB | 87.594 ms (182.7 MiB/s) | 83.003 ms (192.8 MiB/s) | 80.889 ms (197.8 MiB/s) | 22.455 ms (712.6 MiB/s) | 1.08× |

Most of the gap between "classic, no signature" and both signed variants is SHA3-256 over the whole
ciphertext (the signed body hash), not post quantum cost. The PQ-only cost is the column "SealDrop / classic seal".

## Sizes (bytes)

Fixed by the specifications and asserted by the code's constants and tests.

| Item | Post quantum | Classic |
|---|---|---|
| KEM public key | 1216 (X-Wing) | 32 (X25519) |
| KEM ciphertext | 1120 (X-Wing) | 32 (X25519 ephemeral key) |
| Shared secret | 32 | 32 |
| Signature public key | 1952 (ML-DSA-65) | 32 (Ed25519) |
| Signature | 3309 (ML-DSA-65) | 64 (Ed25519) |
| SealDrop per-file overhead | 4522 + 16 per 64 KiB chunk | n/a |

Measured in the e2e run: an 11800 byte file became 16338 bytes (4538 bytes overhead = 4522 + 16 × 1 chunk).
